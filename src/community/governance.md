# Governance

Puddi is a young project with a small community, and it is run informally for now: the maintainers of the [puddi-lang](https://github.com/puddi-lang) organization review changes and make decisions in the open, in issues and pull requests.

A fuller governance model is written down in [GOVERNANCE.md](https://github.com/puddi-lang/puddi/blob/main/GOVERNANCE.md) in the compiler repository. It is a **draft that is not in effect**. It describes:

- the roles of contributors, reviewers and maintainers, and how people move between them;
- how decisions are made, by lazy consensus with a vote as the fallback;
- an RFC process for changes to the language specification and the standard library;
- the release, stability and security policies;
- how the code of conduct is enforced;
- the conditions under which the model takes effect.

Until then, the interim rules in that document apply: discuss significant changes in an issue first, and change the specification only together with conformance cases.
